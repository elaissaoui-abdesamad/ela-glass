# Ela Glass — Vitrier sur mesure

Site statique (HTML/CSS/JS pur). Hébergé sur **GitHub Pages** via `elaglass.ma`.

## Stack
- HTML5 / CSS3 / Vanilla JS
- Pas de build, pas de npm
- GitHub Pages + CNAME

## Déployer
1. Push tout le contenu vers la branche `main`
2. Settings → Pages → Source = `/root`
3. Custom domain = `elaglass.ma` (fichier `CNAME` présent)
4. DNS chez registrar : 4× A sur `@`, 1× CNAME `www`
